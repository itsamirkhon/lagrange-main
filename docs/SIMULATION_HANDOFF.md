# Передача в поток симуляции

В старой версии данных манифест L3 указывал на удалённый месяц 2026-05 в трёх региональных XLSX, хотя эти XLSX на L0 и L3 содержали только месяцы 2025 года. Такая запись не описывает наблюдаемую порчу и искажает оценку обнаружения.

Во время проверки рабочее дерево соседнего `lagrange-sim` активно менялось. В текущем `sim/generator/doc_builders.py` функция `_d2_apply_m1` проверяет `mask.any()` до записи порчи и выбирает наблюдаемый месяц 2026-04; актуальный манифест содержит новые документы и другие записи M1. Требуется подтвердить отдельным воспроизводимым тестом: для каждой записи M1 сравнить исходный и испорченный документ и проверить, что удалённые строки действительно существовали в исходном документе и отсутствуют в испорченном.

Другие вопросы из ревью пользователя для потока симуляции: официальный курс ЦБ на дату, Bx, исключение внутренних ID из клиентских документов и достаточное число случаев на оператор. Конкретные решения и текущий статус должен подтвердить владелец этого репозитория. Не регенерировать и не перезаписывать его незакоммиченные изменения без координации.
